# 与猫 Agent · 六段恋爱日常

手机浏览器中的恋爱互动漫画游戏，包含六道情境选择及个人结果报告。

**试玩网址：https://shark7755.github.io/yumao-agent/**

跟随林初夏与周屿的日常作出选择，逐句阅读对白，解锁不同后续。完成六题后可查看爱情风格、恋爱 MBTI 对比及恋爱寄语，并保存结果卡。报告由预设文案和游戏规则组合，用于娱乐与自我探索。

## 部署

纯静态 HTML/CSS/JavaScript，无构建步骤。GitHub Pages 使用 main 分支根目录发布；提交更新后自动重新部署。

入口为 index.html，assets 包含运行代码、剧情、报告文案与图片。所有资源使用相对路径。玩家进度仅保存于当前浏览器本地。

## 内容使用

本仓库公开用于运行与试玩；公开访问不代表授予漫画、角色及文案的再分发或商用许可。
